# PID Tuning Optimization — Multi-Objective Weight Variation Analysis

This repository contains research experiments on PID controller parameter tuning using
multi-objective optimization. The main focus is analyzing how weight variations in the
weighted-sum method affect real-time PID parameter selection.

---

## 🔬 Features
- Weighted Sum + Hybrid Genetic Algorithm
- PID controller modelling
- MATLAB + Python implementation
- Reproducible notebooks
- Weight sensitivity analysis

---

## 📁 Project Structure
- `python/src` — main algorithms and helper modules  
- `python/notebooks` — experiment notebooks  
- `python/results` — plots, metrics, logs  
- `matlab` — optional MATLAB implementation
